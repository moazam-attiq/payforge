# PayForge API

NestJS application for the PayForge sandbox payment platform.

## Current status

The API is in M0 Foundation. The generated NestJS baseline exists, but configuration validation, logging, request correlation, health checks, PostgreSQL, Drizzle, Redis, and BullMQ have not yet been implemented.

Use the root workspace commands for routine build, typecheck, lint, formatting, and tests. Environment variables and local infrastructure instructions will be documented as those foundations are added.
