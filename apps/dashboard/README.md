# PayForge Dashboard

React and Vite application for the PayForge merchant dashboard.

## Current status

The dashboard is in M0 Foundation. It currently presents the project boundary and foundation status. Authentication, payments, ledger, refunds, API keys, webhooks, events, and audit views belong to later milestones and have not been implemented.

Use root workspace commands for build, typecheck, and lint. The development server uses port `5173` and reads public Vite environment values from the repository-root `.env` file.
